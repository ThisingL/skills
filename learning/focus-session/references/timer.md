# 可选本地计时工具

仅在用户明确要求开始、控制随机学习提醒或获取本次报告时读取。本工具不会成为口述复盘的前置条件。

本技能目录已包含全部计时脚本和报告模板，整目录复制后即可使用，不需要另一个项目或 `runtime.json`。工具面向 Windows，使用 Python 3.8+ 标准库，无需 pip 依赖；`gui` 命令另需 tkinter。其他系统可单独使用口述回顾，勿承诺 Windows 提示音或应用采集可用。

提示音保留原项目的不同场景音频，并随目录分发。用户询问音频文件或对应关系时，读取 [提示音说明](audio.md)。不要擅自替换成系统蜂鸣或合成提示音。

脚本位于本技能目录下 `scripts/timer.py`。在支持本地命令的 Agent 中，用 Python 执行脚本；按实际技能目录解析绝对路径，不依赖调用者的工作目录。按需执行 `gui` 打开控制窗口；可用 `demo --output <文件路径>` 查看虚构报告，不启动提醒或采集。

```text
python <技能目录>/scripts/timer.py start
python <技能目录>/scripts/timer.py status
python <技能目录>/scripts/timer.py pause
python <技能目录>/scripts/timer.py resume
python <技能目录>/scripts/timer.py defer
python <技能目录>/scripts/timer.py stop
```

- `start` 启动独立后台进程，立即返回 JSON。默认随机间隔 3–5 分钟、微休息 10 秒、不设整场上限。这些是可调整起点，不称为科学最佳值。
- 用户提供参数时映射到 `--min-minutes 3 --max-minutes 5 --rest-seconds 10`。只有用户需要固定结束时间才加 `--limit-minutes 60`；该上限包括暂停与休息。`--silent` 可静音。
- 默认不记录前台应用或标题。只有用户明确选择记录本次活动，才加 `--record`。只有另行明确选择窗口标题，才加 `--record --titles`。不为生成更多分析而自动扩大采集。
- `status` 只查当前状态；不要每秒轮询或让 Agent 阻塞等待学习结束。后台程序负责计时。
- `pause` 暂停随机提醒和应用采样；`resume` 重新安排随机间隔；`defer` 跳过当前微休息或重新安排下一次提醒，不扣分。
- `stop` 返回 `summary` 和 `report_path`；正常结束后查询 `status` 也能取得它们。先在对话中简短报告摘要，再附实际 HTML 路径或“查看时间轴”链接；用户要求打开时展示它。不得把“报告已生成”说成“AI 分析已完成”。用户想回顾时，直接在当前对话按 [可选主动回忆](recall.md) 检查理解，无需在 HTML 填表。
- 返回 `already_running: true` 表示已有计时器，未修改它的配置。向用户说明当前已在运行，不宣称新的参数或采集选择已生效。
- 工具错误时报告实际原因。不要在后台循环重试、静默启用其他采集器或安装依赖。
- 运行数据写入系统临时目录，不写入技能目录。控制信息按脚本所在路径区分；移动或更新技能前先结束原会话，避免从不同副本同时启动提醒。

原始会话记录默认只在内存中；结束生成临时目录内的 HTML，应用不索引历史、不自动读取旧报告。临时文件不等于立即自动删除。纯复盘不会访问这些文件。

## 结束摘要与记录粒度

`summary` 包括 `duration_seconds`、`activity_seconds`、`rest_seconds`、`paused_seconds`、`unobserved_seconds` 和两项记录开关。`apps` 按停留时长降序提供最多 8 项，每项包含原进程 `process`、显示名称 `name` 和 `seconds`；其余应用汇总在 `remaining_apps` 的 `count`、`seconds` 中。未开启应用记录时 `apps` 为空。摘要不含窗口标题、逐条日志或知识分数；运行中的会话不提供结束摘要。

应用记录只识别前台进程。`msedge.exe` 显示为 Microsoft Edge，`chrome.exe` 显示为 Google Chrome；它们可能承载视频、文档或任何网页，不能自动等同于 B 站或学习内容。未记录标题时，同一浏览器内切换页面也可能合并成同一段。选择 `--record --titles` 后，窗口实际返回的标题可以帮助区分内容；全屏播放、应用行为或采样间隔仍可能限制粒度。标题不等于页面正文，旧会话没有采集的标题无法补回。

## HTML 报告保存规则

- 有明确默认位置：`<系统临时目录>/random-reminder-<脚本目录标识>/reports/<会话ID>.html`。Windows 通常位于 `%TEMP%`；脚本目录标识用于区分不同 Skill 副本，每次会话各生成一份文件。不要把某台机器的用户名或绝对路径写进技能。
- 用户未指定目录时直接使用默认值，不必在每次学习前追问。结束时以 `report_path` 为准告诉用户实际位置。
- 用户希望存到指定目录时，在启动及之后控制命令中一致使用 `--runtime-dir <目录>`，报告写入该目录的 `reports` 子目录；该选项同时指定控制文件的位置，不是只设置 HTML 文件名。尚在运行的会话不要临时改用另一个目录。
- 临时目录可能被系统清理。想长期保留，可下载当次报告，保存位置由浏览器下载设置或保存对话框决定。网页里的用途分类修改不自动写回原文件，需要下载保留。
- HTML 是孔版印刷风格的当次活动记录：按应用分轨的时间轴（每轨一个应用，直接标注名称与总时长）、一根 24 小时定位条、片段顺序与应用分布，打开即可看；用途标注可选。口述回忆与 AI 纠错全部在 Agent 对话中进行，不写入 HTML。
