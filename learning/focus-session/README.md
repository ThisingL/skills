# focus-session · 专注学习

辅助眼前这一次学习：用随机声音提醒短暂休息，结束后查看时间轴与统计；想回顾时，再用自己的话解释所学，让 AI 帮你检查理解。

每次独立使用。复盘可以跳过，也可以单独进行，无需连续打卡、维护学习计划或安排“下次起点”。学习过程中没有持续倒计时。

## 开始使用

将 **整个 `focus-session` 文件夹**放入所用 Agent 支持的技能目录，包括 `scripts`、`assets` 和 `references`。本目录已包含计时工具、提示音和报告模板，无需原项目或额外安装脚本。

- **本地计时**：面向 Windows，需要 Python 3.8+ 和可执行本地命令的 Agent。只使用 Python 标准库，无需安装 pip 依赖或 FFmpeg。
- **可选控制窗口**：需要 Python 环境带有 tkinter / Tcl-Tk。
- **仅口述回顾**：不需要 Python，也不受 Windows 限制。

在支持 `$技能名` 调用的 Agent 中，可以这样开始：

```text
$focus-session 开始一次专注学习，使用默认随机提醒，不记录应用。
```

默认每 **3–5 分钟**随机提示一次，短休息 **10 秒**，整场不设时限，由你手动结束。启动后由独立后台程序计时，无需让 Agent 持续等待。

学习中可以直接说：

| 想做什么 | 示例 |
| --- | --- |
| 暂停 | `$focus-session 暂停提醒` |
| 继续 | `$focus-session 继续专注` |
| 稍后再提醒，或跳过当前短休息 | `$focus-session 延后这次提醒` |
| 查看状态 | `$focus-session 现在是什么状态？` |
| 结束并看报告 | `$focus-session 结束提醒，打开本次报告` |

参数也可以用自然语言指定，例如：“随机间隔改为 5–8 分钟，短休息 15 秒，这次 45 分钟后结束。”整场时限包含暂停和休息时间。已有会话运行时，再次启动不会修改它的配置；需要改参数时先结束，再开始新会话。

## 听到提示音后做什么

**学习中**照常阅读、写代码或做题，不需要盯时间。**短休息音响起时**，暂时停下输入和阅读，可以闭眼放松或把视线移开屏幕，不必趁这几秒刷手机或刻意复习；听到恢复提示后继续。闭眼是建议，正有思路时也可以延后或跳过。

**整段结束后**，可以起身走动、伸展、喝水或离开屏幕一会儿。长休息由你自由安排，程序不计长休息倒计时，也不会自动开启下一轮。默认间隔和时长只是可调整的起点，不代表适合所有人的最佳学习规律。

提示音保留原项目素材，整场开始和结束使用同一段较长的提示音：

| 场景 | 原音频 |
| --- | --- |
| 整场开始 | `long_rest_start.mp3` |
| 暂停后继续 | `short_rest_end.mp3` |
| 进入短休息 | `short_rest_start.mp3` |
| 短休息结束、跳过当前休息 | `short_rest_end.mp3` |
| 手动结束、到达整场时限 | `long_rest_start.mp3` |

原 MP3/AIFF 保存在 `assets/audio`。Windows 播放从原 MP3 解码得到的 PCM WAV 副本，未重新合成、剪辑或调整音量；使用者无需自行转换。详见[提示音说明](references/audio.md)。

最小化控制窗口会继续运行，**关闭窗口会结束本次学习并生成报告**。检测到锁屏、休眠后的运行中断或超过 15 秒的运行空档时，会自动暂停；回来后手动继续，不补放错过的提醒。

## 可选记录与时间轴

应用记录默认关闭，此时仍可查看会话状态和时长。需要应用停留分布时，明确告诉 Agent：“这次记录前台应用，但不记录窗口标题。”窗口标题需要另外选择，可能包含文档名或页面信息。

开启记录后，程序每约 2 秒采样前台应用；不截图、不读取网页正文。报告打开即可看到按应用分轨的时间轴、片段顺序与应用分布：每条轨道一个应用，直接标出名称与该应用的总时长，休息、暂停和未观测时段单独成轨；下方一根 24 小时定位条说明本次在一天中的位置。

**为什么看 B 站时记录为 Edge？** `msedge.exe` 是 Microsoft Edge 的进程名，浏览器里的全屏视频也属于它。报告会显示友好的应用名，但仅凭进程不能知道具体网站或视频。需要细分时可以明确选择：“这次记录应用和窗口标题。”命令行对应 `--record --titles`；控制窗口中勾选“另外记录窗口标题”。标题能提供多少信息取决于实际窗口，全屏时也不保证能获取视频名；没有采集的历史标题无法补回。

默认无需标注就能查看完整报告。想分析用途时，可以展开可选分类，把片段标为“相关”或“无关”；未分类的保持“待确认”。未开启应用记录时，分类仅代表你对这段时间的自述。分类统计包括：

- **相关占比**：已确认相关时长 ÷ 已分类活动时长。
- **分类覆盖率**：已分类活动时长 ÷ 全部活动时长。

休息、暂停和未观测时段不计入活动分母；分母为零时显示 `—`。窗口停留不等于注意力，不动键鼠也不等于分心。这些统计不用于推断知识掌握程度或给学习质量打分。

## 报告保存在哪里

正常结束时生成一份可离线打开的独立 HTML，默认保存在系统临时目录：

```text
%TEMP%\random-reminder-<脚本目录标识>\reports\<会话ID>.html
```

每次会话各生成一份文件，实际位置以结束命令返回的 `report_path` 为准。Agent 默认先在对话中给出简短时长摘要，再附时间轴链接；你需要时再打开。

网页内的用途分类修改**不会自动写回原文件**。要保留修改，下载当次报告，保存位置由浏览器下载设置或保存对话框决定。临时目录可能被系统清理，需要长期保留的报告请另存。

也可以用 `--runtime-dir <目录>` 指定运行目录，报告会放在其 `reports` 子目录中。启动和之后的控制命令必须使用同一个目录；该选项也决定控制文件的位置，不能在会话中途换用另一个目录。

“每次独立”表示 Skill 不自动检索旧报告、建立学习档案或续接上次计划，**不表示报告文件会自动删除**。未结束的活动记录保存在进程内存中，强制结束进程或重启会丢失；需要报告时请正常结束。

## 想回顾时，再请 AI 检查理解

复盘直接在当前 Agent 对话中进行，无需去 HTML 填表、复制内容，也不必先看时间轴：

```text
$focus-session 我想回顾刚才学到的内容，不用计时。
我的理解是……请帮我看看有没有明显错误。
```

先不看资料，用自己的话说说理解了什么、解决了什么，或卡在哪里。AI 会优先指出一两处有依据的错误，解释较准确的说法与原因；无法确认的细节会说明需要核实。你可以重新解释，也可以随时结束，笔记由你自己整理。

HTML 只展示活动记录，**回顾原话和 AI 反馈留在对话中，不写入报告**。结束命令给 Agent 的摘要包含时长与最多 8 项应用停留，其余应用合并汇总，不附窗口标题或逐条日志。使用云端 Agent 时，你在对话中的讲述与工具返回的摘要会由相应模型服务处理。

## 直接使用本地工具

不经过 Agent 也可以运行。以下命令从本 Skill 目录执行，窗口和命令行启动方式任选一种：

```powershell
# 打开控制窗口，在窗口中开始
python scripts/timer.py gui

# 或直接启动默认随机提醒，不记录应用
python scripts/timer.py start
```

运行中按需控制：

```powershell
python scripts/timer.py status
python scripts/timer.py pause
python scripts/timer.py resume
python scripts/timer.py defer
python scripts/timer.py stop
```

`resume` 重新安排随机间隔；`defer` 延后下一次提醒，休息中调用则跳过当前休息。启动时可加 `--silent` 静音、`--record` 记录应用、`--record --titles` 另外记录标题。完整参数见 `python scripts/timer.py start --help` 和[计时工具说明](references/timer.md)。

只想看看报告样式，可以生成一份标有虚构数据的示例，不会启动计时、采集或播放声音：

```powershell
python scripts/timer.py demo --output demo.html
```

移动或更新 Skill 前先结束正在运行的会话。不同目录的副本各有独立控制信息，避免同时从多个副本启动提醒。
